# Advanced Unreal Engine 5 Plugins & Repositories

A curated reference of advanced, open-source Unreal Engine 5 plugins organized by category.

---

## Procedural Generation

| Plugin | Description | Link |
|--------|-------------|------|
| **RealtimeMeshComponent** | Runtime-generated content rendering for UE5. Supports dynamic mesh creation, collision, and LODs at runtime. | [GitHub](https://github.com/TriAxis-Games/RuntimeMeshComponent) |
| **Procedural Dungeon Generator** | Procedural 3D dungeon generation with mini-maps and mission systems for roguelike games. | [GitHub Topics](https://github.com/topics/ue5-plugin) |
| **Voxel Plugin** | Fully volumetric, destructible, infinite worlds. Advanced voxel terrain with LOD and multiplayer support. | [GitHub](https://github.com/Phyronnaz/VoxelPlugin) |
| **UnrealFastNoise2** | Wraps the FastNoise2 library for Blueprint-friendly procedural noise generation (Perlin, Simplex, Cellular, etc.). | [GitHub Topics](https://github.com/topics/unreal-engine-plugin) |
| **Houdini Engine Plugin** | Integration with Houdini Digital Assets for advanced procedural content pipelines. | [SideFX](https://github.com/sideeffects/HoudiniEngineForUnreal) |
| **ArcGIS CityEngine for UE** | CityEngine procedural modeling capabilities brought into Unreal Engine for urban/architectural generation. | [GitHub](https://github.com/topics/unreal-engine-5) |

## AI & Machine Learning

| Plugin | Description | Link |
|--------|-------------|------|
| **UnrealGenAISupport** | LLM/GenAI integration + MCP UE5 server. Supports GPT, Claude, Gemini, Deepseek, Qwen, Grok (200+ models). Includes automatic scene generation from AI. | [GitHub](https://github.com/prajwalshettydev/UnrealGenAISupport) |
| **HttpGPT** | Async REST integration with OpenAI GPT and DALL-E services for in-game AI features. | [GitHub Topics](https://github.com/topics/unreal-engine-plugin) |
| **UE5-MCP** | Model Context Protocol integration enabling AI agents (GPT-4, Claude) to control the UE5 editor via natural language for Blueprint automation and scene editing. | [GitHub](https://github.com/VedantRGosavi/UE5-MCP) |
| **Reasonable Planning AI** | Utility Reasoning with Goal Oriented Action Planning (GOAP). Data-driven with C++ and Blueprint support. | [GitHub Topics](https://github.com/topics/ue5-plugin) |
| **3D Pathfinding (Sparse Voxel Octrees)** | Advanced 3D pathfinding using Sparse Voxel Octrees for flying AI, underwater navigation, and complex 3D environments. | [GitHub Topics](https://github.com/topics/ue5-plugin) |
| **Mountea Dialogue System** | Complex dialogue tree editor with validation, conditions, and branching narrative support. | [GitHub Topics](https://github.com/topics/unreal-engine-plugin) |
| **Inworld AI Character Engine** | Full AI character platform: animation, behavior, memory, safety, and dialogue for AI-powered NPCs. | [Inworld](https://inworld.ai/blog/best-unreal-engine-ai-plugins-and-which-to-avoid) |
